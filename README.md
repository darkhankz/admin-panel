# Coursee Admin Panel

Админ-панель для управления базой видео Coursee. Чистые HTML/CSS/JS, без сборки и зависимостей.

## Возможности

- Аналитика: всего видео, категорий, добавлений за 7 дней, график за 14 дней, разбивка по категориям
- Опубликовать: вставляете ссылку YouTube, мета подтягивается автоматически, при галочке пост в Telegram-канал
- Видео: поиск, фильтр по категории, пагинация, редактирование, удаление
- Категории: счётчики по 15 категориям, кнопка нормализации категорий в БД

## Настройка (2 минуты)

1. Откройте app.js и впишите вверху две константы:

WORKER_URL — адрес вашего Cloudflare Worker, например https://my-worker.workers.dev
ADMIN_KEY — тот же ключ, что в IMPORT_KEY внутри worker.js

2. В worker.js впишите ваш канал в константу TG_CHANNEL_ID, например @my_channel
(или числовой ID вида -1001234567890). Бот должен быть администратором канала с правом публикации.

3. Задеплойте воркер: wrangler deploy

## Публикация на GitHub Pages

1. Создайте репозиторий, например coursee-admin, и загрузите туда эти три файла: index.html, style.css, app.js
2. Settings - Pages - Source: ветка main, папка root, затем Save
3. Через минуту панель будет на https://ВАШ_НИК.github.io/coursee-admin/

Важно : ключ ADMIN_KEY хранится в app.js в открытом виде и виден всем, кто откроет исходники страницы.
Это осознанное решение для личного использования. При желании скройте репозиторий или добавьте проверку ключа.

## Проверка после деплоя

1. Открыть панель, вкладка Аналитика показывает цифры
2. Опубликовать: вставить тестовую ссылку YouTube, появилось превью, нажать Опубликовать, видео в БД (проверка через /debug-schema)
3. При включённой галочке пост пришёл в TG-канал
4. Повторная публикация той же ссылки выдаёт ошибку дубля
5. Видео: поиск, фильтр, редактирование, удаление
6. Категории: счётчики совпадают с приложением, нормализация работает

## Технические детали

Панель шлёт заголовок X-Admin-Key (или параметр key), воркер сверяет его с IMPORT_KEY.
Эндпоинты: /admin/stats, /admin/publish, /admin/videos, /admin/videos/:id (PATCH и DELETE), /admin/categories.
CORS у воркера открыт на все источники — панель работает с любого статик-хостинга.
